# Boston-House-price-prediction

This project focuses on developing a machine learning regression model to predict Boston house prices based on various housing and socioeconomic features, including the number of rooms, crime rates, property characteristics, and other relevant factors.

The project involved a complete machine learning workflow, including data preprocessing, exploratory data analysis, feature selection, model selection, model training, and performance evaluation. Different features were analyzed to understand their relationship with house prices, followed by training a regression model on the prepared dataset.

The performance of the model was evaluated using appropriate regression metrics such as Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² Score to assess its prediction accuracy.

The final solution demonstrates how machine learning techniques can be applied to housing data to identify important factors influencing property prices and generate reliable price predictions.
